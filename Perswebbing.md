So we are making a personal website. This is a newer and different design than before. Every new thing would be done in the 'Perswebing' folder. You can take anything you need from 'Persweb' folder. 

The design is a collage style, which functions on the idea that everything should be present at the time of opening. The designs can be seen in the new design.jpg and new des.svg. You have already implemented a rough view of it.

The functionality goes like this; when hovered on a card it instantly jumps to the top of the layers with increased depth, and goes back when cursor removed. 
When the cursor is hovering on a card, all the other cards turn to grayscale, and the accompanying card that is attached to the hovering card turns into a text card, telling information about the hovering card.
The grayscale others on hovering a card would not be done, when the cursor hovers on info card.

Clicking on the hovering card would make it cycle through the images while the  attached accompanying text info changes. This happens for every card.
The image structure is the same as the previous site, get the images to cycle from the images folder inside persweb. I have made another folder inside called 'Projects' that is for the top left first card. 
I have added a card names.jpg with annotated names of the cards, for easier identification.

The whole card structure would be in a container in itself so it can scale proportionally with the viewport size. The cards should not change spacing and sizing between them, and keep their distance from the ends of the viewport.

This would be a no scroll website, so I don't want any extra vertical real estate. Any corner elements should be attached to the corners, like we did for the corner buttons in the previous site. 
At the bottom their would be the universal state open button the same size as the site before.
